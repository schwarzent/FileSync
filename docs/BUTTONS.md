# 按钮职责

界面按钮及说明按实际读写范围检查。清单流程为首页；只有执行方案或整目录同步才修改资料。时间、大小和哈希详情默认折叠。

| 位置 / 按钮 | 实际作用 |
| --- | --- |
| 添加资料文件夹 / 添加文件夹 | 保存本机路径和记录位置，创建或加入共同仓库，不扫描资料 |
| 浏览 | 打开 Windows 文件夹选择框；取消保留输入 |
| 扫描并更新清单 | 读取参与记录的本机文件计算哈希，写入 JSON 清单，不复制资料 |
| 局域网交换清单 / 交换清单 | 交换双方已生成的当前及前一清单，不重扫资料 |
| 比较清单并制定方案 | 缺少本机清单时先显示扫描状态并自动生成；已有清单时离线比较，不重扫资料；缺少对方清单时显示交换指引 |
| 勾选并采用较新版本 | 跨所有分页勾选两端都有的同名文件，并选择修改时间较新的一端；时间相同的冲突、目录和独有文件保留原选择 |
| 勾选全部差异 / 清除勾选 | 改变批量操作范围，包括其他页，不改变处理方向 |
| 勾选项采用某设备 / 暂不处理 | 为勾选路径设置或清除处理方向，仍不写入资料 |
| 每项采用某设备 | 选择该设备的此项内容；不存在表示删除另一端对应项 |
| 查看时间、大小与哈希 | 展开原始元数据及本次记录中的修改类型 |
| 预览方案 | 计算双方将发生的修改，展开目录子项及必要父目录 |
| 保存方案 | 只保存 JSON 方案，可随记录文件夹交换 |
| 已保存方案 / 查看方案 | 查看持久化方案，不扫描资料、不连接对方 |
| 查看每个路径采用哪端 | 展开方案的完整路径及来源设备列表 |
| 允许局域网执行 | 共享资料目录并允许已配对设备写入，含修改和删除 |
| 局域网共享权限 / 保存共享 | 查看和修改读写权限与忽略规则；可关闭写入 |
| 连接局域网并检查方案 | 检查选定文件是否仍与记录一致，生成实际执行预览 |
| 执行本方案 | 只传输并修改方案列出的路径，未选文件保留 |
| 移除记录仓库 | 仅移除本机配置，资料、记录和方案文件保留 |
| 新建整目录任务 / 保存任务 | 保存局域网或实际文件 OneDrive 中继任务，不开始同步 |
| 比较整目录 / 预览接收资料 | 扫描并比较参与整目录同步的资料，不立即覆盖 |
| 所选 / 全部保留某端 | 选择整目录同步的冲突处理方式，目录选择包含子项 |
| 应用选择并查看预览 | 更新整目录冲突预览，不写入资料 |
| 执行整目录同步 | 应用整目录预览中的变化，包括预览列出的删除 |
| 将资料写入 OneDrive | 写入实际资料、历史内容及提交记录，仍需等待客户端下载上传 |
| 文件中继历史 / 查看文件修改 / 查看修改前后 | 读取中继提交、原始元数据及历史内容 |
| 继续完成中继写入 | 检查归档后继续完成中断发布，可能修改中继实际文件 |
| 编辑任务 / 移除任务 | 修改或移除任务配置，保留现有资料及历史 |
| 共享本机文件夹 / 停止共享 | 授权或停止配对设备读取与写入，本机资料保留 |
| 配对设备 / 通过邀请配对 | 打开邀请生成及加入表单 |
| 生成配对邀请 / 复制邀请 | 创建一次性邀请或复制到剪贴板，5 分钟有效 |
| 连接并配对 | 使用对方邀请建立双向证书身份关系 |
| 撤销配对 | 阻止该设备访问，移除相关整目录任务及清单连接，保留文件与记录 |
| 版本记录：详情 | 显示本次本机及远端修改和状态 |
| 撤销 | 撤销最近完成的同步；双向任务和方案需两端在线 |
| 恢复同步前状态 | 还原中断同步前的资料，双向操作需两端在线 |
| 取消操作 | 请求取消扫描、暂存或备份；文件应用阶段等待校验完成 |
| 保存名称 | 保存本机设备显示名称 |
| 导出整目录任务 / 导入整目录任务 | 导出配置或选择配置文件并预览，不含清单、方案及资料 |
| 导入任务 | 应用配置预览，按编号合并，保留其他已有任务 |
| 刷新 | 重新读取当前页面对应的状态或历史，不启动同步 |
| 上一页 / 下一页 / 路径筛选 | 只改变当前展示，保留逐项及跨页选择 |
| 关闭 / 关闭预览 / 返回 | 关闭当前窗口或回到按钮指明的历史页面，不执行文件修改 |

需要确认的移除、撤销、恢复窗口使用具体动作作为确认按钮名称，避免单独显示“确认”。
