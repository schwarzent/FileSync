# FileSync 实现约定

Windows 10/11，本地浏览器界面。每条同步任务从指定设备的已发布源文件夹单向同步到本机目标文件夹，只有点击执行才写入目标；新增、覆盖、删除及类型变更均先预览。不提供双向合并或后台自动同步。OneDrive 中继是后续方向，当前不实现。

## 数据与恢复

- 文件比较包含 SHA-256、长度、UTC 修改时间；目录内容由子项决定，目录修改时间在最后自底向上恢复，包含根目录和空目录。
- 执行前重新检查清单；所有文件流式下载并验证后才修改目标。同步期间的外部编辑导致明确失败。
- 被覆盖及删除的本机内容移动到程序数据目录的版本库，记录事务状态；支持恢复中断事务和撤销最近一次同步。可选完整备份位于用户指定目录。
- 不支持符号链接、目录联接、磁盘根目录、网络共享及相互包含的同步目录；路径检查阻止穿越、Windows 设备名及备用数据流。
- 历史记录和备份不自动删除，由使用者管理存储空间。

## 安全

- 局域网接口仅 HTTPS，TLS 1.2/1.3。每台设备生成独立自签名证书，配对后双方按 SHA-256 证书指纹验证，每次请求要求客户端证书。
- 配对邀请包含随机 256 位一次性密钥和服务器证书指纹，5 分钟过期；通过可信渠道在两台设备间复制，勿发给无关人员。
- 私钥通过 Windows 当前用户 DPAPI 加密，不安装系统信任证书。使用 Go 标准库 TLS 进程避免 Windows Schannel 对内存私钥的限制，私钥经匿名管道传递，明文不写入磁盘。该进程嵌入主程序，仅在程序数据目录提取运行，父进程管道关闭后退出。撤销配对后立即禁止该设备访问。
- TLS 进程与业务进程仅经回环接口通信，独立随机凭据认证每次内部请求；远端不能注入设备身份头或调用本机管理 API。
- UDP 广播只发现设备，不能授权访问；发现信息不作为证书信任依据。
- 本地管理界面只监听回环地址，校验 Host、Origin 与会话请求头，远端 HTTPS 端口不提供管理 API。
- 源文件夹只允许已配对设备读取；不暴露任意远端路径，也不接受远端写入。

## 资源

无文件监听器、无自动扫描。设备发现低频广播；扫描单文件流式哈希，传输顺序执行，缓冲区 128 KiB。任务全局互斥，预览保存在磁盘，HTTP 客户端和文件流及时释放，退出时取消发现与传输。
