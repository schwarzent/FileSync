# 文件清单与同步方案

本次目标：各端手动扫描生成仅含相对路径、大小、原始时间和 SHA-256 的清单；通过本机文件夹、OneDrive 或局域网交换清单，离线比较后保存逐项同步方案。局域网连接后只执行方案列出的路径，其他文件不修改。

验收项：

- 生成与交换只保存元数据，不复制资料内容；离线比较和保存方案不扫描资料或连接远端。
- 比较显示两端记录时间、独有文件、修改方向、内容冲突及各端相对上一记录的变化。
- 每项可选择采用本机、采用对方或暂不处理；目录选择所包含的记录子项和必需父目录明确列入方案。
- 方案保存到记录目录，可随 OneDrive 携带，并在重启后查看；冻结双方记录和逐项选择。
- 执行无需创建全目录同步任务；通过已配对局域网设备和明确允许写入的共享传输选定内容。
- 执行前校验方案中涉及的文件；这些文件变化时明确停止；无关文件变化不扩大执行范围。
- 未列入的内容及文件时间保留；新增子项不能被目录删除或类型替换一起带走。
- 执行沿用真实 TLS、哈希检查、版本、恢复与撤销；覆盖、删除和两个方向的修改在执行前可见。
- 主界面以清单比较和方案为主要入口，完整内容 OneDrive 传输明确标注；逐项检查按钮、说明与实际行为。
- 自动验证覆盖离线规划、独立记录目录的文件交换、真实局域网选择执行、未选文件保护、过期计划、结构变更、恢复/撤销及既有功能；每个后端进程保持 60 秒硬超时。
- 更新使用说明，提交 Git，提供验证后的 Windows 运行包。
